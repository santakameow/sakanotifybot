# Sakanotifybot

Telegram-бот на Go и [Telego](https://github.com/mymmrac/telego). После команды `/start` в личном чате бот присылает список активных задач в начале каждого часа по UTC. Если задач нет, он всё равно пишет «Активных задач нет.». Бот также присылает новые записи и обновления из RSS- и Atom-лент.

## Настройка вебхука

Бот не опрашивает Telegram. При запуске он регистрирует вебхук и принимает входящие POST-запросы от Telegram. Нужен публичный HTTPS-адрес с действительным сертификатом; TLS завершает обратный прокси. Сам бот по умолчанию слушает HTTP только на `127.0.0.1:8080`.

Добавьте в `.env` или в `EnvironmentFile` systemd-сервиса:

```dotenv
BOT_TOKEN=токен_от_BotFather
BOT_WEBHOOK_URL=https://bot.example.com/telegram/webhook
BOT_WEBHOOK_SECRET=случайный_секрет
```

Для секрета используйте вывод `openssl rand -hex 32`. Не коммитьте файл с секретами. Если меняете порт через `BOT_LISTEN_ADDR`, поменяйте его и в прокси.

### NixOS: nginx перед существующим сервисом

Направьте DNS домена на сервер, откройте TCP 80 и 443 и добавьте в конфигурацию NixOS (подставьте свой домен и почту):

```nix
security.acme = {
  acceptTerms = true;
  defaults.email = "admin@example.com";
};

networking.firewall.allowedTCPPorts = [ 80 443 ];

services.nginx = {
  enable = true;
  virtualHosts."bot.example.com" = {
    enableACME = true;
    forceSSL = true;
    locations."= /telegram/webhook".proxyPass = "http://127.0.0.1:8080";
  };
};
```

Остановите старый экземпляр бота, обновите вход `sakanotifybot` в серверном flake (если он уже добавлен), выполните `nixos-rebuild switch` и проверьте `journalctl -u sakanotifybot -f`. Без systemd можно запустить `nix run .` с тем же прокси. Затем отправьте боту `/start` в личном чате, если вы ещё не подписаны.

Для круглосуточных напоминаний держите процесс запущенным; пропущенные часы задним числом не рассылаются.

| Команда | Что делает |
| --- | --- |
| `/start` | Включить ежечасные напоминания |
| `/add Купить хлеб` | Добавить задачу |
| `/list` | Посмотреть активные задачи и их номера |
| `/done 1` | Закрыть задачу №1 |
| `/stop` | Выключить напоминания без удаления задач |
| `/subscribe https://discordstatus.com/history.rss` | Подписаться на ленту RSS или Atom |
| `/feeds` | Посмотреть подписки и их номера |
| `/unsubscribe 1` | Отписаться от ленты №1 |
| `/help` | Показать справку |

У каждого чата свой список: до 20 активных задач, до 90 символов в задаче. Подписки и задачи сохраняются в `./data/state.json` относительно рабочего каталога. Для постоянного размещения задайте абсолютный путь через `BOT_DATA_FILE` и запускайте только один экземпляр бота с этим токеном и файлом.

## RSS и Atom

Поддерживаются общедоступные HTTPS-ленты RSS 2.0 и Atom. Это два формата лент; для Discord Status достаточно выбрать один: `https://discordstatus.com/history.rss` или `https://discordstatus.com/history.atom`.

Бот проверяет ленты каждые 5 минут. Первая успешная проверка запоминает текущие записи и не рассылает историю. После этого бот присылает заголовок и ссылку для новых записей и записей, чьё содержимое изменилось (например, инцидент закрыт). Если лента недоступна или URL ведёт не на ленту, `/feeds` будет показывать ожидание первой успешной проверки.

Можно добавить до 5 лент на чат. Подписки и сведения об отправленных записях сохраняются при перезапуске. `/stop` не отключает ленты: для этого используйте `/unsubscribe`.

## Сборка и разработка

```sh
nix build              # ./result/bin/sakanotifybot
nix develop -c go test ./...
go run .               # без Nix, нужен Go 1.26.11 или новее
```
